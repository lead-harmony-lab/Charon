### Automated Doc Queue

**Scope & Rendering**
Visualizes the asynchronous pipeline of documentation generated by the agent fleet (e.g., ADRs, API Specs, System Guides, Changelogs).

**Data Flow & States**
* Tracks tasks through a strict lifecycle: `pending` (queued) → `generating` (agent drafting) → `review` (needs human approval) → `published`.
* **Human-in-the-Loop:** Items in the `review` state require operator intervention. Approving a document mutates its status to `published` (currently local state), representing clearance for Knowledge Base ingestion.
