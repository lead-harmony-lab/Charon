### Knowledge Base Subsystem

**Purpose**
The Knowledge Base serves as the central hub for documenting how the Charon harness and its subsystems function. It provides a single source of truth for developer onboarding, system architecture, design decisions, and technical contracts.

**Subsystem Overview**
* **[Manual Viewer](#user-manual)**: Operational guides, system taxonomy, component maps, and workflow documentation.
* **[ADR Viewer](#adr-viewer)**: Architecture Decision Records capturing the rationale, context, and status of structural choices.
* **[Specs Viewer](#specs-viewer)**: Formal technical specifications, interface contracts, and versioned protocol definitions.
* **[Document Creator](#document-creator)**: Unified form engine enforcing validation rules for new ADR and Spec entries.
